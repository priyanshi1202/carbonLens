# CarbonLens
A Chrome extension for the Google AI Hackathon.
Uses Gemini 2.5 Flash to parse material data and calculates CO2 footprint using verified LCA factors from various sources like springer nature, etc.

## Setup
1. Get a Gemini API Key from Google AI Studio.
2. Replace `YOUR_GEMINI_API_KEY_HERE` in `popup.js`.
3. Load the folder in Chrome via `chrome://extensions` (Developer Mode).
